# Observability

Self-hosted logs, traces, metrics and Grafana dashboards for Cipheroom. Design and rationale:
[`plans/2026-10-07-observability-design.md`](plans/2026-10-07-observability-design.md).

```
api ──OTLP──▶ otel-collector ──▶ Prometheus (metrics) · Loki (logs) · Tempo (traces) ──▶ Grafana
 ▲ ReportCallStats (browsers, every 15 s)        node-exporter, cAdvisor ──▶ Prometheus
 │ Cloudflare GraphQL Analytics (free-tier usage, every 15 min)
browser ──https://<PUBLIC_HOST>/grafana/──▶ tunnel ──▶ nginx (login rate limit) ──▶ Grafana (login)
```

Everything runs at home under the compose profile `observability`; nothing is published, nothing is sent to a
third party (Grafana's usage reporting, update checks and news are off). Off by default: without the profile the
api doesn't export and `/grafana/` answers 502.

## Turning it on

1. **Know what protects it.** `/grafana/` is on the public hostname and protected by **Grafana's own login only**
   — a deliberate choice (no Cloudflare Access). Hardening: anonymous access and sign-up off, accounts locked after 5
   failed logins, nginx allows 6 login-page requests a minute per visitor, sessions expire (7 days idle, 30 max),
   `/metrics` off and the version-revealing health endpoint blocked. Grafana holds call metadata, so **use a long,
   unique admin password** (20+ characters from a password manager). If you'd rather not expose it at all, remove the
   `/grafana/` location from `deploy/nginx/default.conf` and publish Grafana on `127.0.0.1` only.
2. **Secrets** in `deploy/.env` (`scripts/secrets.sh` lists what's missing and generates `TELEMETRY_SECRET`):

   | Value | What it is |
   |---|---|
   | `GRAFANA_ADMIN_PASSWORD` | 20+ characters recommended (12 minimum), typed into the file with an editor (not in a terminal or chat). It's the only thing between the internet and the metadata. Grafana keeps the password it first starts with — change it in Grafana (profile → Change password) afterwards. |
   | `TELEMETRY_SECRET` | Random key for pseudonymous room ids. Generated by `scripts/secrets.sh`. |
   | `CF_ACCOUNT_ID`, `CF_ANALYTICS_API_TOKEN` | Optional. Account id from the dashboard URL; a token with only **Account Analytics: Read**. Without them, free-tier usage is estimated from browser reports. |

3. `scripts/up.sh --tunnel --observability`
4. Open `https://<PUBLIC_HOST>/grafana/` → Grafana login (`admin`) → **Dashboards → Cipheroom**.
   `scripts/security-check.sh https://<PUBLIC_HOST>` verifies nothing is readable without logging in, `/metrics` and
   the health endpoint aren't exposed, and the login page is rate-limited.

## What's recorded

**Never** — keys, envelopes, SDP, ICE candidates, media, display names, IP addresses, user agents, plain room ids,
Cloudflare URLs (they carry key, app and session ids). Enforced in code (`PrivacyProcessor`, `TelemetryIds`, log
levels for `System.Net.Http.HttpClient` and `Polly`) and by `TelemetryTests`.

| Signal | Content |
|---|---|
| **Traces** | One per hub call (`RoomHub/<Method>`) with the room as a keyed hash (`HMAC-SHA256(TELEMETRY_SECRET, roomId)`, 16 hex), the random per-call participant id and the outcome; children: the Mediator command and Cloudflare requests (method, status — no URL). Sampled in the collector: every error, 25 % of the rest. |
| **Logs** | The api's own logs (Information and up), room ids hashed, linked to traces by trace id. |
| **Metrics** | Low-cardinality labels only (method, outcome, operation, platform, path, kind, direction) — never room or participant ids. |

Metrics, as Prometheus names them:

| Metric | From |
|---|---|
| `cipheroom_rooms_active`, `cipheroom_participants_active`, `signalr_server_active_connections` | api |
| `cipheroom_hub_calls_total{method,outcome}`, `cipheroom_hub_rate_limited_total{method}` | api |
| `cipheroom_sfu_request_duration_seconds{operation,outcome}`, `cipheroom_key_envelopes_relayed_total` | api |
| `cipheroom_call_*` — bytes, packets, packets lost, jitter, RTT, freeze time, video height and fps | browser reports |
| `cipheroom_e2ee_*` — frames by result, envelopes dropped, time spent "Securing…" | browser reports |
| `cipheroom_realtime_egress_bytes{service}`, `…_free_tier_bytes`, `…_polled_seconds`, `…_polls_total` | Cloudflare analytics |
| `node_*`, `container_*`, `otelcol_*`, `dotnet_*`, `http_*` | exporters, collector, runtime |

Browser reports (`ReportCallStats`, protocol: [`signaling-protocol.md`](signaling-protocol.md)) carry numbers only and a
coarse platform bucket — computed per stream from `getStats()` deltas in `web/src/app/core/media/call-stats.ts`.

**Retention:** 7 days everywhere (Prometheus also capped at 5 GB), in named Docker volumes.

## Dashboards

Provisioned, read-only, in the Grafana folder **Cipheroom**: **Overview** (api health, signaling, SFU, logs, failed
traces), **Call quality** (bitrate, loss, jitter, RTT, freezes, resolution, E2EE health; filter by platform and path),
**Free tier** (month-to-date egress vs 1 TB, projection, poll freshness, browser-report estimate), **Host &
containers** (machine, every container, the telemetry pipeline itself).

They're generated — edit the script, regenerate, commit both (`scripts/lint.sh` checks they match):

```
python3 deploy/observability/grafana/build_dashboards.py deploy/observability/grafana/dashboards
```

## Troubleshooting

- **Numbers appear late:** the api exports metrics every 30 s, Prometheus scrapes every 30 s, browsers report every
  15 s, usage is polled every 15 min — give it a minute before suspecting the pipeline.
- **Is data flowing?** Host & containers → "Telemetry pipeline": collector received / refused / failed per signal.
  `scripts/logs.sh otel-collector` shows export errors.
- **Free tier empty:** no `CF_ACCOUNT_ID` / `CF_ANALYTICS_API_TOKEN` (the api logs "no Cloudflare analytics
  credentials" at start), or the token lacks Account Analytics: Read (logged as a status code).
- **Docker Desktop (macOS):** "host" metrics are the Linux VM; the disk panel shows the VM disk that holds Docker's
  volumes. cAdvisor needs the Docker and containerd sockets mounted explicitly (done in compose).
- **Locked out of Grafana:** `docker compose -f deploy/docker-compose.yml exec grafana grafana cli admin
  reset-admin-password '<new>'` — typed by you, not in chat.
